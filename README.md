# IAprotocol

Repositório pessoal para versionar o **protocolo de operação para agentes de IA**
(`protocoloClaude.txt`) usado no dia a dia com o Claude, e demais materiais relacionados
ao assunto (notas, variações, experimentos).

## Objetivo

O protocolo define *como* um agente deve investigar e corrigir problemas de engenharia
— priorizando evidência sobre inferência e inferência sobre plausibilidade — independente
do projeto em que for aplicado. Ele está atualmente em fase de teste (local a um projeto
específico) antes de ser promovido para uso global (`~/.claude/CLAUDE.md`) ou compartilhado
com o time.

Versionar aqui permite:

- acompanhar a evolução do protocolo ao longo do tempo (diffs, histórico de decisões);
- testar variações sem afetar a cópia em uso nos projetos;
- manter um local único de referência antes de promover o documento para uso mais amplo.
